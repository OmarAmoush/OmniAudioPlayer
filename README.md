# تطبيق مشغل الصوتيات الشامل (OmniAudioPlayer - .NET MAUI)

تطبيق أندرويد متكامل مبني باستخدام **.NET 8 MAUI** لتشغيل كافة الملفات الصوتية بجميع امتداداتها (`MP3`, `WAV`, `FLAC`, `AAC`, `M4A`, `OGG`, `OPUS`, `WMA`, `AMR`, `AIFF`, `ALAC`, `APE`, `WV`, `MID`, `3GP`, `WEBM`, `AC3` وغيرها).

## المميزات الرئيسية
- **دعم شامل لكافة الامتدادات الصوتية**: فحص تلقائي لذاكرة الجهاز (`MediaStore` + مجلدات النظام) مع مستعرض ملفات مخصص يدعم جميع صيغ الصوت.
- **تشغيل في الخلفية (Background Audio & WakeLock)**: استمرار التشغيل عند إغلاق الشاشة أو التنقل بين التطبيقات.
- **واجهة عربية عصرية (RTL)**: تصميم داكن مريح للعين مع فلترة فورية بالامتداد، بحث سريع، ومفضلة.
- **تحكم متقدم بالتشغيل**: التحكم في سرعة التشغيل (`0.75x` إلى `2.0x`)، تقديم وتأخير `10` ثوانٍ، أوضاع التكرار (`تكرار الكل` / `تكرار المقطع`)، التشغيل العشوائي، ومؤقت النوم التلقائي.
- **الفتح المباشر من مدير الملفات**: مسجل كمشغل صوتيات في نظام أندرويد (`IntentFilter`) لفتح أي ملف صوتي مباشرة من مدير ملفات الهاتف.

## استخراج ملف الـ APK الجاهز للتثبيت بدون تثبيت أي برامج على جهازك (سحابياً)
يتضمن المشروع ملف بناء تلقائي عبر **GitHub Actions** (`.github/workflows/build-apk.yml`):
1. ارفع محتويات هذا المشروع إلى مستودع جديد على حسابك في GitHub.
2. انتقل إلى تبويب **Actions**، وسيقوم الخادم السحابي تلقائياً بتثبيت `.NET MAUI` وتوليد مفتاح التوقيع (`Keystore`) وبناء ملف `com.omniaudio.player-Signed.apk`.
3. حمّل ملف الـ `APK` النهائي مباشرة من قسم **Artifacts** وثبّته على هاتفك فوراً.

## أو البناء بضغطة زر واحدة على جهازك
- **على نظام Windows**: اضغط مرتين على الملف `build-apk.bat`، وسيتم إنتاج الملف الموقع داخل مجلد `OutputAPK`.
- **على نظام Linux / macOS**: شغّل الأمر `bash build-apk.sh`.
